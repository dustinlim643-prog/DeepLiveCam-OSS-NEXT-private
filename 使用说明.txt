DeepLiveCam + OBS 最终使用说明

项目位置：
D:\DeepLiveCam2.7-Pro-0730_OSS_READY

一、根目录只用这 3 个入口

1. 启动：
1_START.bat

2. 停止：
2_STOP.bat

3. 自检：
3_CHECK.bat

其他修复逻辑已经放到 tools 内部，启动脚本会自动处理 OBS 场景，不需要用户手动点一堆脚本。

二、正确链路

DeepLiveCam 原版 UI 选择源脸图片和摄像头
点击 Live / 直播
弹出 Live Preview 换脸窗口
OBS 捕获 Live Preview
Telegram 选择 OBS Virtual Camera

注意：
OBS 不是换脸软件，只负责把 Live Preview 输出成虚拟摄像头。
Telegram 里不要选真实摄像头，只选 OBS Virtual Camera。

三、日常操作步骤

1. 双击：
1_START.bat

2. 等待 DeepLiveCam UI 和 OBS 都打开。

3. 在 DeepLiveCam UI 里点击 Select a face / 选择人脸，选择授权源脸图片。

4. 在 DeepLiveCam UI 里选择摄像头。

5. 点击 Live / 直播。

6. 确认弹出 Live Preview 窗口，并且里面是换脸后的实时画面。

7. Telegram 视频通话里选择：
OBS Virtual Camera

四、当前推荐画质配置

启动脚本当前使用：
--execution-provider cuda
--execution-threads 2
--frame-processor face_swapper_hyperswap
--live-resizable
--live-fps-debug
--similar-face-distance 1.5
--live-face-smooth 0.35
--live-face-fit-scale 1.06
--quality-preset balanced
-l zh

OBS 当前配置：
捕获窗口：Live Preview:Qt625QWindowIcon:python.exe
输出尺寸：1280x720
锐化滤镜：0.18
颜色稳定：contrast 0.06，saturation 0.04
OBS watcher：启动脚本会等待 Live Preview 出现，然后自动刷新一次 OBS 捕获，避免 OBS 过早启动导致黑屏。

五、参照 Pro 文档后的画质判断

参照资料：
https://aixplore.cc/posts/deep-live-cam-2-7-pro-face-swap/

Pro 文档里影响画质的关键点：
1. 256x256 换脸模型比 inswapper_128 更清晰。
2. GFPGAN / GPEN 可以叠加在人脸上做高清增强。
3. 直播保护包含轮廓柔化、预防掉脸、遮挡保护。
4. 脸型修改可以改善源脸和目标脸尺寸不匹配导致的边缘穿模。

当前 OSS_READY 已实现或接近实现：
1. GPEN-256 实时增强已接入，作为当前稳定默认方案。
2. OBS 输出已经固定为 1280x720，并且只捕获 Live Preview。
3. 已加入颜色稳定、边缘 mask、相似度阈值、FPS 调试。

当前还不能等同 Pro 的地方：
1. 主换脸已从 inswapper_128 切到 HyperSwap 256，源头脸部细节上限比 128 模型更高。
2. 默认不再启用 GPEN，优先保证实时 FPS；需要更锐时再在 UI 手动选择 GPEN-256。
3. 已加入单人锁定追踪和 1.06 脸部贴合放大，减少跳脸和边缘暴露。
4. DFM、完整遮挡分割、完整脸型修改还不能直接照搬 Pro 的编译模块。

六、下一步优化方向

优先顺序：
1. 先稳定当前链路：Live Preview -> OBS -> Telegram。
2. 用同一段光线、同一张源图测试 GPEN-256、GPEN-512、GFPGAN 的实际 FPS 和清晰度。
3. 如果当前电脑卡顿，回到 GPEN-256；如果性能足够，再尝试 GPEN-512 或 GFPGAN。
4. 如果主要问题是脸型/边缘穿模，优先更换更接近目标脸角度和脸型的授权源图。
5. 如果单图方案仍达不到真实要求，再进入 DFM 或 256 换脸模型路线。

七、故障处理

没有画面：
1. 先确认 DeepLiveCam 已经点 Live / 直播。
2. 确认 Live Preview 窗口已经出现。
3. 等 3-5 秒，启动脚本里的 OBS watcher 会自动重启 OBS 捕获。
4. 如果仍没有画面，双击 2_STOP.bat 后重新启动。

画面模糊：
1. 优先换更清晰、更正脸、更接近目标脸型的源图。
2. 确认启动脚本使用 face_swapper_hyperswap。
3. 不要把 Telegram 选成真实摄像头。
4. OBS 只能做轻微锐化和颜色稳定，不能把 128 换脸模型变成真正高清模型。

卡顿：
1. 关闭其他占 GPU 的软件。
2. 使用当前默认 balanced。
3. 如果仍卡，后续改成只用 face_swapper 或降低窗口分辨率。

八、换电脑

复制整个文件夹即可：
D:\DeepLiveCam2.7-Pro-0730_OSS_READY

新电脑需要：
Windows
NVIDIA 显卡和驱动
可用摄像头
OBS Virtual Camera 可被 Telegram 识别

脚本使用相对路径，不强制必须放在 D 盘。

注意：
根目录入口使用英文编号，是为了避免中文 bat 文件名在部分 Windows 命令行环境下异常丢失。
